System Architecture

Prism is a high-performance audio spectrum analyzer built on the Texas Instruments CC3200 microcontroller. It captures live audio via a microphone, processes the frequencies using hardware-accelerated math, and maps the data to LED strips with custom gravity physics and color logic.

⚡ Hardware-Accelerated FFT

Utilizes the ARM CMSIS-DSP library to compute a 512-point Fast Fourier Transform. By sampling audio at precisely 16kHz via a hardware timer, the system achieves zero-latency frequency binning using optimized q15 fixed-point math.

🎛️ Custom DSP Pipeline

Raw FFT data is passed through a custom Digital Signal Processing pipeline. This includes a DC blocker, a silence noise gate to prevent LED flicker, and an Exponential Moving Average (EMA) filter to give the falling LED bars a smooth, realistic "gravity" effect.

🧭 Interactive Accelerometer

The visualizer responds to physical orientation. By reading the CC3200's onboard BMA222 accelerometer via I2C, physical tilt is dynamically mapped to the HSV color space, allowing the user to seamlessly shift the hue of the LEDs just by tilting the board.
